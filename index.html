Hardware y Estructura del Proyecto

Componentes del Sistema

Selección de elementos electrónicos que integran el circuito y sus roles en la automatización del aforo.

Cerebro 🤖

Arduino Uno R3

Microcontrolador principal encargado de procesar la lógica de programación, recibir datos de los sensores y activar los actuadores.

🚶‍♂️

Sensor PIR

Detecta automáticamente cada persona que ingresa a la zona de espera, incrementando el contador del sistema (+1).

🔘

Push Button

Utilizado por el operador para registrar la salida de visitantes del área de espera, decrementando el contador (-1).

📺

Pantalla LCD 16*2

Muestra continuamente el conteo en tiempo real, el límite máximo permitido y el estado del área (Disponible / Cerca del límite / Llena).

🚦

LED RGB

Indicador visual tricolor de ocupación: Verde (espacio disponible), Amarillo (cerca del límite) y Rojo (aforo lleno).

🔊

Buzzer

Emite una alerta sonora instantánea cuando el aforo alcanza su capacidad máxima, notificando inmediatamente al personal.

💡

LED Indicador

LED simple que confirma que el sistema está energizado y operando de manera correcta en todo momento.

⚡

Protoboard, Resistencias y Jumpers

Infraestructura de montaje para la interconexión eléctrica, protección contra sobrecorriente y distribución de señales.

Ciclo de Operación

Lógica de Control en Tiempo Real

Secuencia lógica automatizada para la gestión segura del flujo de personas.

  1. 01

    Registro de Ingreso

    El sensor PIR detecta movimiento en el acceso y envía una señal al Arduino para sumar 1 unidad al contador global de aforo.

    Entrada: Sensor PIR
  2. 02

    Registro de Salida

    El operador presiona el Push Button cuando los visitantes abordan la atracción o salen de la zona, restando las unidades correspondientes.

    Salida: Push Button
  3. 03

    Evaluación de Umbrales

    El programa compara el contador actual contra los límites: aforo bajo (<70%), medio (70%-99%) o aforo máximo (100%).

    Procesamiento: Arduino C++
  4. 04

    Visualización e Interfaz

    La Pantalla LCD 16x2 y el LED RGB actualizan su estado al instante para informar tanto al personal como a los visitantes.

    Salida: LCD 16*2 + LED RGB
  5. 05

    Alerta de Seguridad

    Al llegar al límite seguro, el buzzer suena una vez como aviso de detención de paso, previniendo colapsos de plataforma.

    Alerta: Buzzer + Luz Roja
